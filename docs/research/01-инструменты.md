# Исследование 1: инструменты мониторинга инсайдерских сделок

Собрано 2026-07-30 (обход сайтов + обзоры). Основа для проектного документа.

## 1. OpenInsider (openinsider.com) — эталон бесплатного, детально

**Возможности.** Бесплатный, real-time (обновление 6:00–22:00 ET), данные напрямую с sec.gov. Готовые скринеры: Latest Cluster Buys, Latest Penny Stock Buys, Latest Insider Trading, Latest Insider Purchases / $25k+, Latest Officer Purchases $25k+, Latest CEO/CFO Purchases $25k+, зеркальные по продажам ($100k+), Top Insider/Officer Purchases/Sales за Today/Week/Month, Insider Buy-Sell Charts (агрегатные графики).

**Поля таблицы:** Filing Date (до секунды), Trade Date, Ticker, Company, Insider Name, Title, Trade Type, Price, Qty, Owned (позиция после), **ΔOwn %** (фирменная метрика), Value, колонки **доходности после сделки: 1d / 1w / 1m / 6m**. Флаг «D» — derivative-related. В группировке по компании — Company Totals: число филингов, инсайдеров, офицеров, суммарный объём, суммарный ΔOwn%.

**Поля скринера (полная схема):** тикеры, имя инсайдера, цена (min/max), ликвидность Lqdty M$ (прокси капитализации), Filing/Trade Date (пресеты + диапазон), **Filing Delay (min/max дней сделка→подача)**, N Days Ago, тип транзакции (10 кодов), «No deriv», «Multiple Days», Traded K$, Own Chg %, сектор (грубый SIC), должности (Officer/COB/CEO/Pres/COO/CFO/GC/VP/Director/10%own/Other), группировка Filing/Company + фильтры по агрегатам компании, сортировка.

**Чего не хватает:** только США; нет market cap/GICS; нет алертов/API/экспорта; **нет тега 10b5-1**; нет рейтинга успешности инсайдера; нет ценового контекста (просадка/максимум); cluster = примитивная группировка ≥2; perf только до 6m; архаичный UI.

## 2. Finviz
Лента последних сделок + топы недели. Поля стандартные + ссылка на Form 4. Сила — общий скринер акций (Insider Transactions % как фильтр). Нет ΔOwn/cluster/должностей. Elite $39.5/мес: real-time, экспорт, алерты.

## 3. SecForm4.com
Real-time парсинг EDGAR; insider + 13D/13G + институционалы; **Graph View — сделки поверх графика цены**; buy/sell ratio по компании. Слабый UX, мало производных метрик.

## 4. InsiderScreener.com
**16 стран**; ~17 пресетов: largest buys/sells, cluster, **«Buying the dip»** (после −5%+), executive-only, earnings-related. Уникальное: **Insider Rankings** (win rate и средняя доходность инсайдера по горизонтам), **Activity Signals** (отклонение активности от бейзлайна компании, рутинные vs оппортунистические, confidence score), **Realised Performance** (только закрытые циклы). Подписка: алерты, экспорт.

## 5. Quiver Quantitative
Инсайдеры + конгресс-трейдинг + лоббизм/госконтракты; **бэктестеры стратегий на сайте** (Alpha, Sharpe, CAGR, MaxDD, Win Rate). Инсайдерская часть слабее конгрессной. Premium + API.

## 6. TipRanks
Daily Insider Tracker + Insiders' Hot Stocks (Very Positive/Positive confidence). Ключевая идея — **«Informative Buy» vs неинформативные**; рейтинг топ-инсайдеров; фолловинг конкретных инсайдеров с push (Ultimate). Закрытая методология, жёсткий пейволл.

## 7. MarketBeat
Фильтры: страна, сектор, **market cap (Mega→Nano)**, размер сделки; трекеры CEO/CFO buys/sells; конгресс. All Access: скрещивание с MarketRank/Media Sentiment/Analyst Consensus, CSV, скринер. Нет ΔOwn/cluster.

## 8. Barchart
Лента 5 дней + **график buys vs sells за 60 дней**; обновление 2 раза в день. Premier: скринер, экспорт.

## 9. GuruFocus
**Double Buys** (инсайдеры + гуру-фонды), **Triple Buys** (+ net buyback компании), CEO/CFO Buys, Cluster Buys, Канада/Китай. **Insider Trends**: агрегатный buy/sell ratio vs S&P 500 и по секторам — таймер дна рынка. Дорого (~$500+/год).

## 10. InsideArbitrage
Скринеры: Cluster Purchases, **Insider Buys Near Highs** (сигнал продолжения), **Flip Floppers** (хаотично меняющие направление — фильтр шума), **Top Performing Insiders**, покупки префов, IA Score; C-Suite Performance Report; событийный контекст (buybacks/spinoffs/merger-arb).

## 11. VerityData / InsiderScore — профессиональный эталон (300+ фондов)
- Очищенный контекстный датасет с 2003/2004, ручная проверка: тегирование 10b5-1, отсев шума (RSU/налоговые), **point-in-time версии** (без look-ahead bias).
- Поведенческие паттерны: cluster buying; **инфлексии против 90-дневного бейзлайна** (инсайдер изменил привычное поведение); **cessation of selling** (систематический продавец замолчал — недооценённый бычий сигнал); trading into strength/weakness.
- Контекст: «культура продаж» компании; персональная история каждого инсайдера; оценка 10b5-1-планов.
- Смежные датасеты: buybacks/авторизации (15 лет, $10T), management changes, ATM-offerings, 13F/13D/13G, equity grants. ~2500 брифов/год, API.

## 12. 2iQ Research — профессиональный, глобальный
60 000+ акций, 58 стран, история с 2000, ~3000 транзакций/день (FactSet, WRDS). **Нормализация должностей: ~100 стандартных ролей с иерархией**. Теги: Options Related, M&A-related, Automated (10b5-1). Сигналы: масштаб сделки относительно богатства/истории инсайдера, ранг, кластеры во времени.

## 13. Кратко
- **StockTitan**: live-лента + AI-оценка значимости и AI-саммари каждого Form 4 (Rhea-AI), фильтры по бирже/капе/флоату, push (Gold).
- **insidertrades.com**: real-time push, watchlist.
- **Smart Insider** (с 1994): stock rankings с учётом стажа директора, трек-рекорда, ценового контекста; point-in-time; API/SFTP/Snowflake.
- **Simply Wall St**: sentiment по open-market сделкам, владение, дилюция; глубины нет.

## 14. Агрегатные индикаторы настроения
- **Vickers Weekly Insider (Argus)**: sell/buy ratio по числу транзакций (1-нед и 8-нед сглаживание). Пороги: **<2.00 бычий, 2–6 нейтрально, >6 медвежий**. Исторически ловит дно рынка.
- **Barron's Insider Transactions Ratio** (еженедельно, данные Vickers): $продаж/$покупок; пороги **<12:1 бычий, >20:1 медвежий**.

# Синтез: что позаимствовать (по убыванию ценности; [PRO] = только у платных)

1. **Фильтр информативности** — только open-market P, исключить гранты/опционы/налоговые/10b5-1 («Informative Buy»). Фундамент.
2. **Cluster buys с параметрами** + company totals (N инсайдеров/офицеров, $, ΔOwn).
3. **ΔOwn %** — покупка относительно имеющейся позиции.
4. **[PRO] Инфлексия против персонального бейзлайна** — «не покупал 5 лет — и вдруг купил». Выводится из истории EDGAR.
5. **[PRO] Cessation of selling** — систематический продавец перестал продавать.
6. **Рейтинг успешности инсайдера** — win rate и доходность его прошлых покупок (1/3/6/12м).
7. **Пост-сигнальная доходность в таблице** (1d/1w/1m/6m…).
8. **Ценовой контекст**: «Buying the dip» и отдельно «Buys Near Highs».
9. **Ранг должности с нормализацией** [PRO: ~100 ролей]; CFO-покупки исторически самые информативные.
10. **Filing Delay фильтр** + «Multiple Days».
11. **Triple/Double Buys**: пересечение с 13F гуру и net buyback.
12. **[PRO] Тег 10b5-1/автоматических сделок** — парсится из футноутов.
13. **Агрегатный термометр** Vickers-style (общий + по секторам) с порогами <2 / >6.
14. **Скрещивание с фундаменталом**: капа, сектор, short interest, earnings-близость.
15. **Алерты по правилам** (Telegram/push).
16. **Фолловинг конкретных инсайдеров**.
17. **[PRO] «Культура продаж» компании** — нормировка на историческую норму эмитента.
18. **Flip Floppers-фильтр**.
19. **Масштаб сделки vs состояние/компенсация инсайдера** [PRO] (прокси: vs медиана его сделок, vs компенсация из DEF 14A).
20. **AI-саммари футноутов**.
21. **Buyback-контекст** [PRO].
22. **Realised Performance** (закрытые циклы).
23. **График цены с наложенными сделками**.
24. Глобальное покрытие [PRO] — низкий приоритет.
25. **Point-in-time**: момент доступности сигнала = подача, не сделка — обязательное правило бэктеста.

**Ключевой вывод:** почти все [PRO]-сигналы (4, 5, 12, 17, 19, 21, 25) не требуют платных данных — выводятся из бесплатного EDGAR (Form 4 + футноуты + DEF 14A + buybacks из 10-Q) накоплением истории и нормализацией по персоне/компании. Профессионалы берут деньги за очистку, тегирование, персональные бейзлайны и point-in-time целостность — именно это и надо строить поверх скелета скринера OpenInsider.
