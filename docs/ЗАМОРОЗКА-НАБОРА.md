# Заморозка набора перед слепой проверкой на 2006–2015

Документ фиксирует ВСЕ параметры до того, как будет получен хоть один результат на
holdout-периоде. Он коммитится раньше первого прогона намеренно: второго нетронутого
куска истории у проекта нет, и любая правка после взгляда на результат уничтожает
смысл проверки безвозвратно.

Состояние кода на момент заморозки: коммит `f77620dc`, самотестов 59.

## Параметры рабочего набора

| Параметр | Значение | Где в коде |
|---|---|---|
| близость к 52-недельному максимуму | не ниже **−7%** | `SET_MAX_DD` |
| минимальная сумма сделки | **$50 000** | `SET_MIN_VAL` |
| минимальный дневной оборот бумаги | **$3 000 000** | `SET_MIN_DV` |
| срок удержания | **3 месяца** | `SET_HOLD_MONTHS` |
| вес позиций | равный по тикерам | `portfolioSeries` |
| минимальный оборот для портфеля | $3 000 000 | `PORT_MIN_DV` |

Все три условия набора известны на дату сделки. Просадка считается по колонке `close`
(скорректирована на сплиты, но не на дивиденды).

## Правила измерения

- **Вход**: закрытие первого торгового дня ПОСЛЕ даты подачи формы. Не по дате сделки.
- **Портфель**: календарно-временной (Jeng–Metrick–Zeckhauser) — на конец месяца берутся
  все бумаги с квалифицирующей подачей за последние 3 месяца, равный вес, держим месяц.
- **Значимость**: Ньюи–Уэст с лагом 3.
- **Бенчмарк**: SPY.
- **Альфа**: к трём факторам — рынок, размер, моментум. Моментум обязателен, потому что
  набор по построению сидит в победителях моментума.
- **Контроль**: портфель ВСЕХ бумаг, побывавших в том же ценовом контексте в том же
  месяце, собранный тем же способом и на тот же срок.
- **Издержки**: 0.5% на круг для нетто-показателя.

## Гейты информативности

Применяются в порядке из `scripts/lib/gates.mjs` на коммите `f77620dc`, без изменений:
`cancelled`, `reassigned`, `badvalue`, `security`, `offering`, `drip`, `espp`, `forced`,
`units`, `newlisting`, `noliq`, `capacity`, `outlier`, `discount`, `sync`, `fund`,
`planned`, `routine`, `regular`.

Гейт `discount` — в исправленной редакции: отсев требует одновременно «дешевле закрытия
на порог» И «ниже минимума дня сделки и предыдущего дня». Минимумы для holdout-периода
берутся из снимка Sharadar.

## Определение вселенной для holdout

**Зафиксировано до прогона.** Вселенная — обыкновенные акции США, торговавшиеся на бирже
в дату сделки, по данным Sharadar: наличие ценового ряда, покрывающего дату, и площадка
из множества NYSE / NASDAQ / AMEX / NYSE ARCA / NYSE MKT / BATS.

Восстанавливать каждого подателя Form 4 не пытаемся: около 30% эмитентов 2006–2013 — это
внебиржевая мелочь, которую текущая вселенная тоже отсекает. Сопоставление формы с ценами
идёт каскадом: тикер формы → `relatedtickers` Sharadar → CIK, с проверкой, что дата
сделки попадает в диапазон ценового ряда.

Замеренное покрытие на пробе (docs/ПЛАН-СЛЕПОЙ-ПРОВЕРКИ.md): 93.5% эмитентов рабочего
набора на калибровочном отрезке 2016–2019.

## Период проверки

Подачи форм с **2006-01-01 по 2015-12-31**. Данных ранее у Sharadar нет (ценовые ряды
начинаются 1997-12-31, но датасеты SEC доступны с 2006q1).

Периоды 2016–2026 в холдаут НЕ входят: их видели все решения проекта.

## Три исхода, записанные заранее

| Исход | Трактовка |
|---|---|
| превышение над SPY положительно и t > 2 | эффект подтверждён вне выборки; порядку +5–7% можно доверять |
| превышение около нуля (\|t\| < 2) | набор — артефакт отбора на 2016–2026; относиться как к ставке, а не к стратегии |
| превышение отрицательно | эффекта нет, панель требует пересмотра |

Дополнительно смотрим, но НЕ используем для смены вердикта: 2008–2009 отдельно от
остального периода. Лонг-онли набор с моментум-наклоном в кризис обязан провалиться;
это информация о профиле риска, а не опровержение.

## Что запрещено делать после первого взгляда на результат

- менять любой параметр из таблиц выше;
- менять определение вселенной или правило сопоставления;
- исключать годы, отрасли или отдельные имена;
- пересчитывать «ещё раз, но с поправкой на X».

Разрешено: считать дополнительные ДИАГНОСТИКИ (разбивка по годам, по размеру, по
отраслям) — при условии, что вердикт по трём исходам выше уже зафиксирован.

## Честное ожидание, записанное до прогона

Набор отбирался перебором на 2016–2026, в том числе перебором 2240 комбинаций для одного
только порога близости к максимуму. Превышение над индексом на видимом периоде держится
на t≈1.85, что ниже медианы шума 2.25 по собственной линейке проекта.

**Ожидаю, что на 2006–2015 результат окажется заметно слабее заявленного, и считаю
наиболее вероятным второй исход — превышение около нуля.**
