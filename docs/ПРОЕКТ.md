# Проект идеального инсайдерского дашборда — синтез исследований

Дата: 2026-07-30. Основа: [01-инструменты](research/01-инструменты.md),
[02-литература](research/02-литература.md), [03-данные-form4](research/03-данные-form4.md).

## 0. Философия продукта

Профессиональные сервисы (VerityData/InsiderScore — 300+ фондов, 2iQ — FactSet/WRDS) берут
деньги **не за данные** (данные — бесплатный EDGAR), а за четыре вещи:

1. **Очистку** — отсев ложных покупок/продаж (гранты, налоги, PIPE, cashless-исполнения);
2. **Тегирование** — плановость (10b5-1), рутинность, событийный контекст;
3. **Персональные бейзлайны** — история каждого инсайдера: инфлексии, трек-рекорд, «культура продаж» компании;
4. **Point-in-time целостность** — сигнал существует с момента подачи, бэктест без look-ahead.

Все четыре воспроизводимы на бесплатных данных накоплением истории и нормализацией.
**Цель продукта: OpenInsider-скелет + четыре PRO-слоя + честный бэктест.** Это и есть ниша,
которую не закрывает ни один бесплатный инструмент.

## 1. Конвейер информативности («пирамида фильтрации»)

Каждая сырая строка Form 4 проходит ступени; на каждой ступени часть строк уходит из
сигнального канала (но остаётся в данных с тегом — для контекста и отладки):

```
Сырые строки Form 4/4A
 ├─ G1. Дедуп: 4/A → замена построчно; joint filings → одна сделка на accession
 ├─ G2. Код P, A/D=A, Table I, shares>0, price>0 (S — в контекстный канал)
 ├─ G3. Санити: цена в [0.1×, 10×] рынка дня; own согласован с прошлой формой
 ├─ G4. Отсев ложных P (открыторыночность):
 │      · |цена − close дня| / close ≤ 3–5% (и не равна цене известного размещения)
 │      · сноски без rights offering / SPA / private placement / subscription /
 │        underwritten / DRIP / ESPP-маркеров
 │      · не синхронная многофилерная подача (N филеров, одна дата, одна цена = размещение)
 ├─ G5. Филер: физлицо officer/director. 10%-owner-юрлица (LP/LLC/Fund/Capital/…) —
 │      отдельный дисконтированный канал, НЕ участник кластера
 ├─ G6. Принудительность: сноски margin call / pledge / divorce → исключить
 ├─ G7. Плановость: чекбокс aff10b5One OR сноска /10b5-?1/i → тег planned
 └─ G8. Рутинность (CMP): тот же календарный месяц ≥3 лет подряд ИЛИ регулярные
        объёмы/интервалы → тег routine (вес 0 в скоре; >50% сделок — шум)
= «Информативная покупка» → скоринг
```

Обоснование: вся документированная альфа сидит в остатке после G7–G8
(оппортунистические сделки: ~82 б.п./мес против ~0 у рутинных — Cohen–Malloy–Pomorski 2012).

## 2. Модель данных

**Сущности:**
- **Сделка** (trade): accession, форма, даты (сделки/подачи/deemed), эмитент CIK, код,
  агрегат vwap по строкам, own после, D/I, теги конвейера (G1–G8), сноски (сырые + распарсенные
  флаги), filing_delay, окно (window-open / внеоконная).
- **Персона** (owner CIK — стабилен сквозь компании): роль на дату сделки (флаги is* первичны,
  титул нормализован regex-иерархией), история сделок, **трек-рекорд** (hit-rate и средний excess
  прошлых информативных покупок по горизонтам), типичный размер сделки, паттерн регулярности,
  статус flip-flopper, co-filing связи (граф совместных подач → склейка фонд/GP/партнёр).
- **Эмитент** (issuer CIK): тикер-история (CIK→тикер на дату), биржа, «культура продаж»
  (базовая интенсивность S), эмпирическое blackout-окно (гистограмма сделок vs earnings-даты),
  цены (close + adjclose), капитализация (v3), short interest (v3).
- **Кластер**: ≥2 (сильный: ≥3) **уникальных физлиц** после склейки co-filing graph и
  «By Spouse/Trust» в окне; окно 5–14 дней (сильный сигнал по Alldredge 2019 — 2 дня;
  наше окно цепочки 30 дней оставить для группировки, но скоринг-бонус давать по плотному ядру).
- **План 10b5-1** (v3): дата принятия из Remarks, cooling-off, red flags по Larcker 2021.

**Point-in-time инварианты:** сигнал существует с даты+времени подачи (в EDGAR есть
timestamp принятия); вход бэктеста — закрытие первого торгового дня после подачи; поздние
подачи — от подачи; поправка 4/A меняет сигнал только с даты самой поправки.

## 3. Скоринг v2 (каждый вес обоснован литературой)

Гейты (не баллы): не-рутинная, не-плановая, открыторыночная P физлица-инсайдера.

| Компонент | Баллы | Обоснование |
|---|---|---|
| Кластер: 2 физлица | +18 | Alldredge 2019: +0.9 п.п./мес к одиночной |
| Кластер: ≥3 физлиц | +30 (нелинейно) | практика 2iQ/VerityData: 4–8% за 6–12 мес |
| Роль: CFO | +20 | Wang/Shin/Francis 2012: CFO +5%/12м к CEO |
| Роль: CEO/През | +14 | «CEO знает больше всех» — миф |
| Роль: директор | +12 | Ravina&Sapienza 2010: почти как исполнительные |
| Роль: прочий офицер | +10 | |
| Роль: 10%-физлицо | +4 | short-swing защита слабее, мотивация иная |
| Трек-рекорд: hit-rate прошлых покупок ≥60% (n≥3) | +15 | Ali&Hirshleifer 2017: trait, >1%/мес |
| Инфлексия: первая покупка за ≥3 года | +12 | VerityData-паттерн; обратная сторона CMP |
| Материальность: ΔOwn ≥50% / ≥20% / ≥5% | +12 / +8 / +3 | $50k при позиции $100k ≫ $500k при $50M |
| Размер: ≥$1M / ≥$250k / ≥$50k | +10 / +7 / +3 | Seyhun 1998: крупные сделки топов |
| Внеоконная покупка (вне window-open потока) | +8 | аномалия относительно blackout-механики |
| Покупка против высокого short interest (v3) | +8 | Wang 2023: BHAR +1.44%/квартал |
| Ценовой контекст: просадка ≥30% от 52w-high | +6 | buying-the-dip; часть = value/reversal |
| Ценовой контекст: покупка у 52w-high (≤5%) | +6 | InsideArbitrage: сигнал продолжения |
| Exercise-and-hold >30 дней (v3, Table II) | +5 | Aboody 2008: +1.4% |
| Просрочка подачи >10 дней | −5 | сигнал устаревает; Brochet 2010 |
| Свежесть: decay-вес | ×(0…1) | 1.0 первые 2 недели → 0 после ~6 мес |

Рядом со скором всегда показывается **cap-bucket** (micro/small/mid/large): эффект
концентрирован в small/micro (LL2001: 4% vs ~0 у крупных), но там же риск ликвидности —
это осознанный трейд-офф пользователя, не компонент скора.

## 4. Медвежий канал (несимметричный!)

Обычные продажи НЕ штрафуются (JMZ 2003: альфа продаж ~0). Медвежьи флаги — только:
1. Плановые продажи с красными флагами Larcker 2021: cooling-off <30 дней, single-trade план,
   план принят перед отчётностью (−2.5% industry-adj).
2. Крупные внеплановые продажи не-рутинного инсайдера с сильным трек-рекордом (Ali&Hirshleifer:
   короткая сторона значима только у «доказанных»).
3. Cessation of buying + «молчание» при рисках (Gao 2021: молчание хуже продаж) — продвинутый флаг.
4. Strategic gifts: крупные G перед отчётностью (Avci/Schipani/Seyhun).
5. J-коды с распоряжением и мутными сносками (margin/foreclosure/in-kind).
6. **Cessation of selling — наоборот, БЫЧИЙ флаг**: систематический продавец замолчал (VerityData).

## 5. Экраны

1. **Лента** — скелет OpenInsider (все его поля скринера, включая Filing Delay и ΔOwn) +
   скор с разбором + теги конвейера + колонки perf 1d/1w/1m/6m + текущая цена.
2. **Скринер сигналов** — пресеты: кластеры; CEO/CFO buys; инфлексии («не покупал 3 года»);
   внеоконные; dip-buys; near-high-buys; cessation of selling; покупки против short interest.
3. **Карточка тикера** — график цены со сделками (сделано в v1) + культура продаж, эмпирическое
   blackout-окно, история кластеров, buyback-контекст (v3).
4. **Карточка инсайдера** (новая сущность!) — трек-рекорд персоны across компаний, паттерн
   регулярности, текущие позиции, «доказанный оппортунист» бейдж; фолловинг (алерт на персону).
5. **Статистика/бэктест** — срезы по всем компонентам скора (валидация весов на своих данных),
   контроль size-бакета, категория делистнутых.
6. **Термометр рынка** — Vickers-style sell/buy ratio (8 недель, только чистые P/S!) общий и
   по секторам, с порогами <2 бычье / >4 медвежье; NPR-оверлей — режимный, не сигнальный.
7. **Алерты** — Telegram по правилам (кластер ≥3, скор ≥70, watchlist тикеров и персон).

## 6. Бэктест-методология

- Вход: закрытие первого торгового дня после **подачи**; горизонты 3/6/12/24 мес (63/126/252/504 т.д.).
- Эталон: excess vs SPY (v1) → v2: **+ size-matched бенчмарк** (IWM для small/micro, SPY для
  large) — иначе альфа завышается почти вдвое (LL2001: 7.8%→4.8% после контроля size/B&M).
- Делистнутые: закрываются последней ценой, отдельная категория (сделано в v1); эмитенты без
  цен — честный счётчик непокрытия.
- Ёмкость: фильтр по среднему дневному $-объёму; помнить — долларовые прибыли скромны
  (Cziraki&Gider 2021), альфа в мелких неликвидных именах.
- Не гнаться за скоростью: 1.5–2.5 п.п. съедается в первые дни после подачи (Brochet 2010),
  но дрейф живёт 6–12 мес (и short-swing блокирует инсайдеру выход на 6 мес — сигнал
  среднесрочный по конструкции).

## 7. Статус реализации: v2 сделана

**v2 реализована 2026-07-30.** Что подтвердилось на реальных данных (квартал 2026q1, 3 340 покупок):
**32% «инсайдерских покупок» не являются информативным сигналом** и отсеиваются конвейером:

| Причина отсева | Строк | Что это |
|---|---|---|
| только юрлицо-десятипроцентник | 390 | фонды (Opaleye, Horizon Kinetics) — не инсайдеры-люди |
| синхронная подача по одной цене | 219 | закрытие размещения, а не кластер |
| реинвестирование дивидендов | 116 | механика DRIP |
| размещение по сноске | 75 | PIPE / rights offering / SPA |
| не обыкновенные акции | 68 | привилегированные, варранты |
| план 10b5-1 | 65 | из них 94 нашлись по сноскам против 65 по чекбоксу |
| программа сотрудников | 47 | ESPP / 401(k) |
| дисконт к рынку | 38 | цена ниже рынка ≥8% |
| рутинная/регулярная (CMP) | 40 | на одном квартале мало; на 10 годах будет >50% |
| аннулирована / принудительная / выброс / единицы | 17 | |

Отдельная находка при валидации: **систематическое несоответствие единиц**. У TSM отношение
цены сделки к котировке равнялось 0.17 у всех сделок подряд, у ADV — 0.04, у VEEE — 0.027.
Это не размещения, а три разные причины: обратные сплиты (Yahoo пересчитывает исторические
цены задним числом), ADR-коэффициенты и привилегированные акции в той же таблице формы.
Наивный гейт «дисконта» пометил бы всё это как PIPE. Решение: сплит-факторы из событий Yahoo
(точное восстановление номинальной цены), фильтр класса бумаги по SECURITY_TITLE и
пер-эмитентная калибровка остатка с отдельной причиной `units`.

## 8. Roadmap: v1 → v2 (сделано) → v3

**v1 уже умеет:** датасеты SEC 2016+ + живой контур EDGAR; P-агрегация по accession; дедуп 4/A
(по содержательному ключу); вселенная NYSE/Nasdaq; кластер ≥2 owner-CIK/30 дней; скор
(кластер/роль/размер/ΔOwn/просадка/10b5-1-чекбокс); форварды 3/6/12/24 vs SPY с категорией
делистнутых; карточка тикера с графиком; Telegram-каркас.

**Честные слабости v1 (найдены этим исследованием):**
1. ~~Кластер считает юрлица~~ — фонд+GP+партнёр могут дать «кластер ×3» на одном PIPE. **Хуже
   всего: PIPE/размещения вообще не отсеиваются** — «кластерная покупка со скором 76» может
   быть допэмиссией. → G4+G5 это главный фикс.
2. 10b5-1 только по чекбоксу → вся история до 04.2023 «чистая». → сноски + рутинность CMP.
3. Нет трек-рекорда/инфлексий — главные PRO-фичи.
4. Дедуп 4/A не обрабатывает аннулирования.
5. Нет perf-колонок 1d/1w/1m/6m в ленте (фирменная фича OpenInsider).

**v2 — СДЕЛАНО (2026-07-30):**
1. ✅ Парсинг сносок с привязкой к строке транзакции (`*_FN` в TSV, `footnoteId` в XML):
   10b5-1, offering/PIPE/rights/SPA, DRIP, ESPP, margin/foreclosure, weighted-average, траст.
2. ✅ Отсев ложных P: дисконт к рынку (порог шире при weighted-average цене), синхронные
   подачи по одной цене, сплит-корректная номинальная цена.
3. ✅ Честный кластер: только физлица; склейка связанных филеров через граф совместных подач
   (union-find); плотное ядро в окне 14 дней отдельно от цепочки в 30 дней.
4. ✅ Рутинность CMP (тот же календарный месяц три года подряд) + регулярные серии.
5. ✅ Трек-рекорд и инфлексии по owner CIK, строго point-in-time.
6. ✅ Perf-колонки 1д/1н/1м/6м, лаг подачи, теги конвейера, санити-фильтры.
7. ✅ Size-бенчмарк: IWM для small/micro по $-обороту (объём добавлен в ценовой кэш),
   в статистике переключатель «size-бенчмарк ↔ SPY».
8. ✅ Экран «Инсайдеры» — рейтинг по доле удачных прошлых покупок.
9. ✅ Аннулирующие 4/A (мягкий флаг: исключаются из сигнала, остаются в данных).
10. ✅ Класс бумаги: привилегированные/варранты/ноты отсеиваются, ADS остаются.
11. ✅ Экран «Статистика» получил срез по причинам отсева — самопроверка гейтов на своих данных.

**v3 (новые бесплатные источники):**
- Market cap + сектор: companyfacts (sharesOutstanding) + SIC из submissions API.
- Earnings-даты (для окон): даты подач 10-Q/K/8-K из EDGAR — бесплатно и точно.
- Short interest: FINRA (2×/мес, бесплатно).
- Buybacks: 10-Q парсинг (сложно) или объявления 8-K.
- DEF 14A: компенсации (масштаб сделки vs зарплата), состав аудит-комитета.
- 13F пересечения (double/triple buys а-ля GuruFocus).
- Деривативная таблица: exercise-and-hold.
- Медвежий канал целиком (§4) + термометр (§5.6).

## 8. Анти-паттерны (не делать)

- Не штрафовать обычные продажи; не считать все 10b5-1 грязными (сигнальны только флагованные).
- Не взвешивать CEO выше CFO/директоров.
- Не скорить рутинные сделки (>50% всех — шум).
- Не считать юрлиц участниками кластера; не считать PIPE покупкой.
- Не гнаться за интрадей-скоростью (не масштабируется — FRL 2025).
- Не верить бэктесту без size-контроля и делистнутых.
- Не строить маркет-тайминг на агрегатном NPR как основном сигнале (in-sample артефакт).
- Не смешивать transactionCode с колонкой A/D; не суммировать Table II с Table I без пересчёта.
