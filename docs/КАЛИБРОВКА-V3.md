# Калибровка скоринга v3 — 2026-07-30

## Метод

Дисциплина против переобучения: выборка расщеплена по времени подачи —
**train = 2016–2021** (45.8 тыс. закрытых 12м-окон у прошедших гейты, включает COVID),
**validation = 2022+** (33.1 тыс.). Эффект фактора = винзоризованное (1%) среднее e12
категории минус база выборки. **В скор вошли только компоненты, чей знак совпал в обеих
половинах.** Веса выставлены по величине train-эффекта (×2 для шкалы 0–100) и заморожены;
перекалибровка — не чаще раза в год и только с новым validation-окном.

Признак Ali–Hirshleifer в нашей аппроксимации (окно перед 10-Q/K вместо дат
earnings-анонсов) воспроизводится только со строгим порогом и в разы слабее
литературных цифр. Возможная причина: 10-Q подаётся через дни–недели после
пресс-релиза с цифрами, окно «перед 10-Q» не совпадает с окном «перед анонсом».
Уточнение через 8-K item 2.02 — кандидат в v4.

## Результат: скор v3 на расщеплённой выборке (12 мес, винзор)

| Корзина скора | train | validation |
|---|---|---|
| <10 | +2.8% | **−11.6%** |
| 10–24 | +6.7% | −3.5% |
| 25–39 | +9.1% | +0.7% |
| 40–54 | +20.5% | −0.9% |
| 55+ | +39.7% | **+7.4%** |

Края разделяются и вне выборки (разрыв низ/верх 19 п.п. на validation против плоского
v2), середина немонотонна. Оговорка: отбор компонентов делался с оглядкой на validation,
поэтому validation больше не полностью «вне выборки» — остаточный selection bias есть.
Настоящая проверка v3 — данные, которых ещё не существует: пересмотр через год.

## Главная честная оговорка

Даже «прото-скор по знакам train» на validation немонотонен: кросс-секционная
дискриминация внутри прошедших гейты покупок вне выборки **слабая**. Скор v3 —
это осторожное ранжирование ожидания с урезанными весами, а не предсказатель.
Ценность системы в порядке убывания: (1) гейты (доказанный отсев шума),
(2) агрегатный режимный сигнал (вспышка покупок в панику), (3) скор.
